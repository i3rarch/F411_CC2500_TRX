# CC2500 STM32F411 Black Pill Project

Проект для работы с радиомодулем **CC2500** на базе микроконтроллера **STM32F411CEU6** (Black Pill).

### Подключение CC2500 к STM32F411

| CC2500 Pin | STM32F411 Pin | Функция    |
|------------|---------------|------------|
| VCC        | 3.3V          | Питание    |
| GND        | GND           | Земля      |
| CSN        | PA4           | Chip Select (активный низкий) |
| SCK        | PA5           | SPI Clock  |
| MISO       | PA6           | Master In Slave Out |
| MOSI       | PA7           | Master Out Slave In |
| GDO0       | PB0           | General Digital Output 0 (RX Interrupt) |
| GDO2       | PB1           | General Digital Output 2 |
| -          | PA0           | **TRX_SEL** (Выбор режима TX/RX) |

## Режимы работы

Режим работы определяется автоматически при старте микроконтроллера в зависимости от состояния пина **PA0**:

*   **TX Mode (Передатчик):** PA0 подтянут к 3.3V (HIGH). Устройство отправляет пакеты "PING" каждые 500 мс.
*   **RX Mode (Приемник):** PA0 подтянут к GND (LOW). Устройство слушает эфир и выводит принятые пакеты в USB консоль.

## USB CLI Интерфейс

Проект поддерживает управление параметрами радиомодуля через USB Virtual COM Port (CDC).
Подключите плату к ПК и откройте терминал (например, PuTTY или Serial Monitor).

**Доступные команды:**

| Команда | Аргументы | Описание |
|---------|-----------|----------|
| `help` | - | Показать список команд |
| `get_status` | - | Получить статус чипа (PartNum, Version, State) |
| `dump_regs` | - | Дамп всех регистров в отладочную структуру |
| `set_freq` | `kHz` | Установить частоту (2400000 - 2483500 кГц) |
| `set_power` | `dBm` | Мощность TX (1, 0, -2 ... -30 дБм) |
| `set_mod` | `type` | Модуляция (2fsk, gfsk, ask, msk) |
| `set_baud` | `rate` | Скорость (1200, 2400 ... 500000 бод) |
| `set_dev` | `kHz` | Девиация частоты (до 500 кГц) |
| `debug` | `on/off` | Включить/выключить подробный лог приема |
| `reboot` | - | Перезагрузка МК |

## Сборка и прошивка

### Требования
- **ARM GCC Toolchain** (arm-none-eabi-gcc)
- **Make**
- **STM32CubeMX** (опционально, для модификации конфигурации)

### Сборка
```bash
make clean
make all
```
